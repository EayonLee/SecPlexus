## Questions and bugs

Use [GitHub Issues](https://github.com/EayonLee/SecPlexus/issues):

- search existing issues first;
- use the bug report form for reproducible defects;
- use the feature request form for proposals;
- include the revision, operating system, Go/Node/pnpm versions, exact commands,
  expected and actual behavior, and sanitized logs.

Support is community best effort. There is no commercial SLA.

## Security

Never report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md)
and use [private vulnerability reporting](https://github.com/EayonLee/SecPlexus/security/advisories/new).
