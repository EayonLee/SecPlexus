## Deferred logos

Zustand and Recharts remain in use; this pass did not confirm a suitable standalone upstream SVG/PNG logo. SCS, Argon2id, pgx, limiter, opt and json-iterator also remain dependencies without a confirmed logo for this gallery. They are omitted from the README gallery pending verification; no dependency is removed for lacking a logo.

Hey API and LiteLLM are not currently used and have been removed from the gallery and its unused assets.
