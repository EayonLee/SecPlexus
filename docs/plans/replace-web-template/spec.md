# Web 模板整体替换与 IAM 重建

> 密码行为以 [简化密码策略](../simplify-password-policy/spec.md) 为准；本文的其他功能和验证范围保持不变。
> 当前页面收敛与按需接入规则已由[安全工作台计划](../web-workbench/spec.md)承接；下文保留整体替换时的范围记录。

## 已确认范围

整体删除旧 Web，以选定的 Next.js/shadcn 模板重建 SecPlexus Web，并恢复已经交付的 IAM 登录和管理功能。保留模板核心样式、组件与页面布局，继续使用 Next.js App Router。Go 后端、数据库和 HTTP 契约保持不变。

## 行为与边界

- 原 Arco 页面、样式、依赖、Mock 与项目 Arco Skill 整体移除，不建立旧前端兼容层。
- 固定模板基准提交 `89f28da674fb847592f46573c8ac6d5ea37e5eb3`，保留核心 UI、日历、主题、字体与页面布局，不重新设计；依赖版本保持该基准。许可随模块保留，来源在根 README 鸣谢中说明。
- 产品名称、元数据、示例身份和帮助链接改为 SecPlexus。删除作者推广首页、统计脚本、托管发布、Git hooks 等不需要的配置和内容；保留仪表盘、认证演示页面及核心组件。不保留额外的基准清单文件或检查命令。
- 原版 `/dashboard`、`/auth` 页面仍是模板演示；项目实际入口 `/login`、`/home`、`/management`、`/account` 使用真实 IAM，不能把演示用户切换当作登录。
- 重新实现 Cookie/CSRF 登录、主动改密、退出与全部退出、设备撤销、近期认证、个人资料、组织上下文、八个管理入口、角色授权及预览。会话和权限仅保存内存投影，保留跨标签退出与组织切换旧请求隔离。
- 组织数据与平台操作继续由服务端授权；菜单只是能力投影。内部接口不向浏览器开放；不把内部服务凭证传给 Next 浏览器代码。
- 新增页面复用原始 shadcn 组件、语义 token 和布局模式，不覆盖官方样式，不修改 `components/ui`、`components/calendar` 或主题。
- 根启动、构建、预览、Compose 与测试更新为 Next 运行方式，保留配置加载边界、同源代理和测试隔离。
- 前端依赖、Vitest/Playwright 配置与测试放在 `src/apps/web/`；根命令只统一编排，根锁文件统一管理依赖。所有项目技能保留在根 `.agents/skills/`。

## 验收

1. 核心 UI、日历及主题样式与固定模板版本一致；Arco 依赖和旧实现不存在，项目文案与配置不再指向作者站点。
2. 类型、构建及项目新增代码检查通过；真实 IAM 核心 E2E 与后端契约检查通过，未验证项明确记录。
3. 登录、主动改密、管理中心、授权拒绝、跨标签退出、SSE 撤权和多组织隔离保持可用。
4. 浏览器检查原版模板及项目页面，覆盖主题、必要交互和窄屏；仅修复项目接入问题，不重设计上游。
5. 配置、架构、测试、贡献指南和 Skill 引用与实现同步。
