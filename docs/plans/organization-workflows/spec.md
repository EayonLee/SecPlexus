# 组织管理与敏感操作流程

状态：用户于 2026-10-30 批准整套方案并要求开始修改；实施及验收完成。

## 已核实的现状

- 当前组织详情读取顶栏组织上下文 `org_id`，API 为 `GET /api/v1/iam/orgs/{id}`；不是“本人唯一所属组织”。
- 上游模板和 Web 已有完全一致的 Base UI Combobox；现有 UserPicker 却使用独立 Input 加 Select，只查询前 50 个结果，没有后续分页。
- 用户查询已有 q、limit、offset、total 和服务端排序，优先复用，不为分页选择新造接口。
- 组织标识现为 3–63 位小写字母、数字和连字符；名称现为 1–100 字符。Go、Zod、数据库均有参与校验，不能只改输入框。
- 目前仅平台成员管理和平台组织管理两类写权限需要近期认证；组织内成员、角色、当前组织名称修改以及读取不需要。近期认证窗口为 5 分钟，从登录或最近一次确认密码计时。该规则由后端执行，超级管理员也不豁免。

## 产品契约

### 命名与范围

组织管理下“组织设置 / Organization settings”改为“当前组织 / Current organization”，与“全部组织 / All organizations”对应。创建表单“初始组织管理员”改为“组织管理员 / Organization administrator”。不增加解释段落，字段和导航表达范围。初始化实现中的 initial 与既有 API 字段 admin_user_id 不必为显示文字更名。

### 成员搜索选择

直接复用已安装的 shadcn Combobox，不改组件基准、不另加 UI 库；一个可输入且带展开按钮的控件完成搜索和选择。展开先加载 10 条，滚动接近列表底部继续查询后 10 条，直到 total 耗尽；输入按服务端搜索重置分页。禁用成员可显示状态但不可选，最终启用状态与权限由后端复核。

分页、缓存与取消用 TanStack Query useInfiniteQuery 和现有 Axios/module API；缓存沿用身份作用域。只在弹层打开时请求，已有请求未结束时不重复拉下一页。保留已选成员对象用于回显，不能因搜索词变化或选中项不在第一页而丢失标签。加载、空结果、失败重试以及键盘选择使用原组件/标准状态。滚动加载不是虚拟化，不预先引入虚拟列表库，也不宣称组件自带远程无限加载。

同一 UserPicker 的组织管理员、添加已有组织成员等消费者一并更新，不保留双控件旧实现。

### 名称与标识

以下是 SecPlexus 的建议规则，不称作行业统一规范：

| 字段 | 规则 |
| --- | --- |
| 组织名称 | 1–30 个 Unicode 字符；允许中文、英文、数字、常见标点和内部空格；去除首尾空白，拒绝纯空白和控制字符；不强制英文小写 |
| 组织标识 | 3–30 个字符；允许 a–z、0–9、下划线、连字符；字母开头、字母或数字结尾；标识唯一，创建后不变 |

显示名称和技术标识用途不同。数字保留是为了支持 soc2、team-2026 等合理命名，不能机械照搬“仅英文”导致现有组织名不能表达。限制由 Zod、模块 Go DTO/用例及数据库约束一致实施；Unicode 长度口径统一，不能让浏览器 UTF-16 长度与数据库字符长度产生相反判断。

新增迁移调整组织字段约束，不改历史已发布迁移。先检查已有组织及初始化名称；存在不符合新规则的数据时报告冲突并停止，不自动截断、改写或删除。无需新增兼容接口，也不能默默改变现有组织标识。对其他业务名称的共享校验不做全局缩短。

### 就地身份确认

保留现有两类平台高影响写操作的保护，不扩展到读取、成员选择或普通组织内配置。将默认近期认证窗口由 5 分钟改为 30 分钟固定窗口；登录/成功确认密码更新计时，普通业务操作不自动续期。30 分钟是本平台权衡，不套称外部标准。

只在服务端明确返回 iam.recent_auth_required 时，同一个 Dialog 内切换到确认密码步骤，不跳页、不叠加第二个 Dialog。原业务表单实例和草稿保留；确认成功后回到原表单，由用户继续提交，不自动重放 HTTP 或自动执行写操作。切换使用现有动画能力/简短过渡，并支持减少动态效果偏好；标题、焦点和错误状态随步骤更新。

- 密码错误留在确认步骤，显示可恢复错误，不清空原草稿、不登出有效身份。
- 返回原表单不丢内容；关闭整个对话框遵守原有取消与清空规则。
- 密码只留在确认表单内存，结束后清空，不进 URL、浏览器持久化、全局 MutationCache、日志或截图。
- 身份确认沿用 IAM 既有 typed credential use case、SCS/session 轮换、CSRF、请求作用域取消和能力刷新；不增加第二套身份状态或网络重放器。
- 真正登录身份失效仍回登录，不冒充可原地恢复；业务版本冲突仍按原规则处理。
- Account 页面移除独立“确认身份”操作，保留账号与密码功能；身份确认仅在相关操作中出现。配置托管唯一管理员规则保持不变。

## 证据与取舍

- [shadcn Combobox](https://ui.shadcn.com/docs/components/base/combobox) 和 [Base UI](https://base-ui.com/react/components/combobox) 支持输入与选择、异步搜索和选中项回显；后端分页由应用数据层提供。
- [TanStack Infinite Queries](https://tanstack.com/query/latest/docs/framework/react/guides/infinite-queries) 提供 pages、fetchNextPage、hasNextPage 等原语，不自行维护第二份分页缓存。
- [GitLab 命名规则](https://docs.gitlab.com/user/reserved_names/) 区分显示名称与 slug，字符集规则并非一套。上述 30 字符等限制为本项目设计决定。
- [GitHub sudo mode](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/sudo-mode) 对已登录用户的高影响操作进行再次认证并提供复用窗口，说明这类保护有成熟实践；不照搬其完整产品或两小时窗口。

## 非目标

不换组件框架、主题或字体，不新增 MFA、SSO、会话系统、完整搜索服务或虚拟化库，不扩大权限，不修改配置管理员的不可编辑规则，不开展部署/CI/容器工作，不执行 Git 写操作。
