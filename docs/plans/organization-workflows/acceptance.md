# 组织管理流程验收

日期：2026-10-30。用户已批准整套方案；在 `settings-design` 完成实现。本轮不暂存、提交、推送、部署或构建容器。

## 实现结果

- 组织管理采用“当前组织 / Current organization”“全部组织 / All organizations”，组织管理员选择字段不再带“初始”措辞；当前组织上下文和权限范围保持。
- UserPicker 使用现有 shadcn/Base UI Combobox 和 TanStack useInfiniteQuery，复用 IAM 搜索与分页 API，首批 10 条、滚动续页、禁用候选不可选，保留选择回显。原搜索框加 Select 的实现删除。
- 使用组件原生 Portal container 能力处理与 Radix Dialog 的集成，仅透传属性，不改上游样式或新增浮层层级数值。Dialog 的 Escape 钩子避免父弹框吞掉组合框关闭事件。
- 组织名称由模块请求模型规范化，1–30 个 Unicode 字符并拒绝控制字符；标识为 3–30 位约定字符。前端 Zod、Gin 请求模型与新增数据库约束同步。迁移原子拒绝不合规现存数据，不截断或改名。
- 默认近期认证窗口改为 30 分钟，既有两类平台写权限仍由 IAM 保护。FormDialog 内完成确认，RHF 原表单保留挂载；会话替换取消旧请求及清理缓存，同时保持当前页面和组织上下文。错误密码、返回、正确确认均保留草稿，成功确认后不自动提交。
- Account 的独立确认入口移除。确认密码不经 MutationCache、持久化或 HTTP 重放。当前用户普通改密、配置托管唯一管理员和服务端鉴权不变。
- 使用 RHF useFormState 的显式订阅驱动字段错误，避免稳定 form 对象在 React Compiler 下留下旧渲染。错误出现时显示组织字段的格式要求，管理员选择有原生 ref、失焦、必填、错误属性和焦点支持；不增加常驻功能介绍。

## 发现及修复

首次 E2E 因测试文件在 Playwright 的模块模式下使用 import.meta 而未进入用例，改为按测试入口解析工作目录。实际界面运行随后暴露浮层鼠标事件拦截和展开清空搜索的问题，分别通过原生 Portal container 与删除错误的生命周期赋值修复。

增加用例后，反复登录同一个测试管理员触发了真实账号限流。API fixture 改为仅在内存复用一次真实登录，过期 fixture 仅修改当前测试浏览器逻辑会话；未提高生产限额、添加重试或清理共享限流桶。

Chrome 首轮发现 Escape 关闭父弹框及字段错误缺失，纳入真实 E2E 后修复。复验还捕获关闭重开后输入词与请求条件不一致；搜索状态改为跟随输入与实际选择，不在展开时另行清空。最终完整 11/11 和唯一人工修正确认通过。

## 隔离与交付状态

所有验证使用远程 PG 的随机自有库及已获授权的 Redis DB0，仅清理自有账号/会话的精确键，共享来源桶按 TTL 到期；不执行 FLUSH、前缀清理或使用正常开发数据构造测试。浏览器仅访问独立 Preview 与临时账号，没有读取原始 Network/CDP 事件、请求体、头、Cookie 或登录事件，也未输出凭据。

正常开发入口已应用新迁移并就绪，保持 localhost:5173 供用户查看；该启动与隔离测试分开，不改写组织名称或标识来迁就约束。隔离栈和临时目录在人工退出后按所有者清理。没有执行 Git 写操作或外部 CodeRabbit 审查。
