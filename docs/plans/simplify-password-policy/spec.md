# 简化密码策略与本地默认连接

按本次明确指令实施：普通密码为 8–128 个 Unicode 字符，保留编码/最大字节/哈希成本边界。初始化与普通密码设置使用同一策略。初始化只创建空库账号，不能每次重启重置已有用户。

删除首次登录/管理员重置后的强制改密策略：移除业务状态、拦截、DTO 字段、结果码、页面分支、临时密码有效期及相关当前文档。保留普通账号安全页、主动改密、近期认证、账号禁用/锁定、会话撤销与审计。新用户和重置密码后的用户登录后直接获得其已有授权。

历史已执行的迁移不改写，新增版本移除不再使用的两列，保留账号、密码哈希及其他数据。同步版本检查、OpenAPI/生成物和稳定测试；旧字段不作为长期兼容协议保留。

根示例/模块配置/Compose：管理员初始化密码默认 secplexus，PG 与 Redis 密码默认 secplexus。同步当前本地连接配置及持久组件认证，不删除容器数据卷。已有账号密码不随配置覆盖自动重置。

Redis 用户名、Compose ACL 与默认凭据的补充要求已由 [Redis 配置审查](../redis-acl-and-configuration-review/spec.md) 承接。使用外部服务时只连接，不修改账号；修改已有 PostgreSQL 角色密码不能以删除数据卷代替。

验收：8 位通过、7 位失败；默认管理员可初始化并直接登录；创建/重置后无需改密仍正常授权；主动改密继续撤销旧会话；升级保留原账号；带密码的 PG/Redis 连接及无密码拒绝正确；单元、真实集成和 Playwright 核心流程通过。
