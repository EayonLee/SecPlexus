# 启动与配置可维护性

状态：用户批准立即实施，保留当前工作分支，不提交代码

## 范围

完成当前文档纠错、启动预检、安全配置诊断、配置来源核对、配置操作说明和干净工作副本验收六项。沿用已有 HTTP、Viper/YAML、原生 Next 环境配置与模块边界，不增加部署、CI、许可证或发布治理工作。

## 行为

- 根启动先校验全部选中模块的运行配置，再执行迁移和启动；后一个模块配置错误不能导致前一个模块已迁移
- `pnpm config:check [iam console web]` 与各模块的 `check-config` 离线校验，不连接基础设施、不执行迁移、不创建业务日志
- 配置错误指出字段及类型或约束，不输出配置值、密码和凭证；根启动保留模块的安全诊断
- 进程环境优先于根 `.env`；Go YAML 声明变量与默认值；独立 Web 使用原生 `.env.local`；根运行无需复制子模块环境文件
- 当前文档的路由、超级管理员、HTTP、命令与链接符合实现，中英文含义一致；历史计划保留历史事实
