# 设置体验与配置超级管理员验收

日期：2026-10-29，功能分支 `settings-design`。用户纠正后本轮重新验收；此前合并个人设置及侧栏锚点的实现已被替换，旧的 8/8 结果不作为本轮证据。不暂存、提交、推送、部署或构建容器。

## 实现范围

- Settings / 设置进入 `/settings/profile`；侧栏 Profile / Account 分别对应独立页面。System / 系统管理进入能力过滤的管理区域。中英文头像菜单均用短单行标签。
- Profile 使用纵向资料字段、右侧真实头像摘要和组织归属；Account 使用账号、密码、身份确认分区。共享主体 Shell、字体与主题；自然宽按钮、细分隔线，移除重复大卡片。
- 设备页面、列表与撤销操作、公开 API、客户端模型和专用查询全部删除。登录、退出、期限与版本校验、密码变更撤销、二次认证和权限 SSE 保留。
- 管理任务统一为成员与权限、组织管理、审计日志；平台成员负责身份生命周期，组织成员负责组织关系，权限边界未合并。
- 所有分页数据表默认 10 条，复用模板 Select、TanStack Table、首末页和前后页控件，支持 10/20/30/40/50。角色详情成员表一致。修改条数回第一页，缓存键包含条数及身份作用域。
- 说明改为短句、无尾句号和手动换行。配置指定的唯一超级管理员仍不能通过本人、平台或运维入口修改资料、密码及身份；凭据仅由配置管理。普通成员改密保留。

## 隔离与限制

测试只使用远程 PG 中本次随机独立库和 Redis DB0 中自有账号/会话精确键，不清库或扫描清理共享键。Preview 使用随机端口和临时凭据；不读取或修改正常开发数据，不停止用户重新启动的开发服务。隔离栈结束需验证服务正常退出、敏感日志排除及资源所有者清理。

普通成员完整操作由真实 E2E 及组件测试覆盖；人工轮若未操作会明确记录。不进行移动端适配、部署、远程 CI 或 CodeRabbit 外部审查，不声明设计评分或全平台无缺陷。

首次 Preview E2E 的三个失败是无句号文案尚未同步到精确断言；新增分页用例另因登录跳转未结束即导航而中断登录。核实真实页面后同步文案，并在登录 helper 等待工作台 URL 就绪；保留权限拒绝和会话失效断言，未提高重试或超时。完整复验 9/9，测试栈正常退出，实际 Console SSE 观察取消及双副本敏感日志排除检查通过。

人工 Chrome 检查未构造超过 10 条的数据；跨页与修改条数后的真实请求由完整 E2E 覆盖。所检查的控制台未记录 error/warn，网络未记录 HTTP 4xx/5xx，存在导航预取取消的 ERR_ABORTED。两张仅保留页面标题/配置说明的局部截图位于忽略目录，不包含凭据，不作为提交资产。

验收代理读取完整网络事件时曾把临时测试账号的登录凭据及 CSRF 值带入工具输出；没有另存或复述这些值。已将其视为泄露，退出测试会话、关闭自有标签并销毁整个自有隔离数据库、会话和临时目录，账号及凭据不再复用。应用日志的敏感值排除检查通过；这不等同于工具输出未出现凭据。正常开发数据与账号不受影响。

本轮隔离入口正常退出 0，Console SSE 观察取消并正常结束，临时目录已移除，正常开发端口保持监听。词典最后清理了已删除功能的权限标签并统一平台成员语义，Web 35 单元、类型与四份业务目录导出检查再次通过。未执行 Git 写操作。
