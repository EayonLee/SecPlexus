# 个人设置与管理中心体验优化

状态：用户已授权新建功能分支并直接实施。范围仅桌面 Web；保留模板字体、主题和组件基准，不开展移动端适配、部署或 Git 交付。

## 产品目标

降低进入管理功能时的选择成本，按用户任务组织导航。个人设置、组织内授权、平台账号生命周期是不同职责；合并入口不合并授权边界。真实 IAM 数据和能力投影决定可见内容，不新增假数据、虚构指标或没有后端支持的编辑能力。

## 信息架构

- 头像菜单：Settings / 设置、System / 系统管理、退出，使用一致的图标、固定最小菜单宽度和单行标签，避免中英文换行。
- 个人设置：两个真实页面 `/settings/profile` 与 `/settings/account`，专属侧栏只有 Profile / 个人资料、Account / 账号。分区根入口跳 Profile，不再使用同页锚点；共享项目 Shell，不照搬 GitHub 导航外壳。Profile 纵向排列身份资料，Account 承载密码和必要的身份确认。删除登录设备页面、列表、单设备撤销及批量退出功能；保留登录、普通退出、敏感操作二次认证和服务端会话安全。
- 管理中心：仅三个任务入口：成员与权限、组织管理、审计日志。通过页内标签承载成员/角色/平台成员、当前组织/平台组织、组织/平台审计，标签按能力过滤。原有管理深链继续定位真实页面；侧栏选中任务入口而非枚举每个子页面。
- 平台成员用于创建、停用与重置平台身份；组织成员用于组织内成员关系，角色用于组织内授权。以文案明确差异，禁止把平台权限当成组织权限或反之。
- 删除“认证与安全”只读概览及无人消费的 API、模型和权限目录项；不删除认证策略、限流、会话保护或个人账号安全能力。

## 组件与交互

- 组织切换使用现有 shadcn Select；仅一个组织时保持可见名称，切换仍不越权或串标签上下文。
- 语言按钮点击直接切换 en/zh-CN，保留 next-intl、Cookie、待提交禁用与错误反馈，不增加第三语言。
- 语言、主题配置和明暗按钮统一 ghost，无常驻实心底色，保留可访问标签、焦点和禁用态。
- 状态使用统一语义 Badge：成功/启用为绿色，失败/禁用为红色，警告/拒绝为琥珀色，信息为蓝色，中性分类保持中性；始终保留文字。共用语义令牌提供明暗主题对比，不在业务页面散写颜色。
- 移除标题下重复标题的大卡片。页面标题、页内导航、工具栏、内容依序排列。设置表单采用纵向字段与自然宽操作，保存按钮自然宽度，不横跨无关空白。
- 个人资料以真实身份资料和组织归属提供上下文，不添加头像上传、邮箱修改或伪造“完善度”。敏感标识放次要区域。

## 验收

导航能力组合、URL 组织上下文、语言切换和语义状态有定向单元验证；类型、格式、相关 Go 测试、常量生成检查和真实浏览器管理/改密流程通过。浏览器仅桌面浅色/深色、中英文，一次集中检查、一次修正确认。测试服务结束后只关闭自有隔离栈，不操作用户重新启动的正常开发服务；不提交、不推送。

## 配置托管的唯一超级管理员（用户追加并确认）

用户进一步确认：配置指定的账号是唯一最高权限账号，不能在平台内被编辑、停用、移除、授予/撤销身份、后台重置密码或自助改密；密码只由配置管理。

沿用 IAM 现有 `bootstrap.username/password` 配置项，明确其从“仅首次初始化”改为持续权威来源，不增加另一份管理员配置。显式迁移及 IAM 启动同步配置账号和密码；配置不变时保持哈希、身份版本和有效会话不变，凭据或身份变更时撤销受影响会话并写审计。各 IAM 副本必须使用相同配置；配置变更后重新启动生效。凭据只传 IAM，不传 Console/Web 或日志。

数据库以部分唯一索引限制最多一个超级管理员。新迁移收回旧的可分配超级管理员标记并撤销其旧会话，随后由配置重新指定唯一账号；保留原用户和组织数据，不删除旧账号。迁移/配置错误不得以继续启动或无管理员降级掩盖。不得对正常开发数据库执行本轮迁移测试。

删除授予/撤销超级管理员的路由、DTO、服务、权限目录、客户端和 UI 操作。所有资料/成员关系/密码写入从后端事务边界拒绝配置账号；个人设置显示“由配置管理”，保留只读资料、密码确认及普通退出。普通账号仍支持原有资料、改密与管理流程。运维重置命令同样不能绕过该限制。

补充验证：重复同步幂等、配置密码变更且旧会话失效、唯一性约束、配置账号切换不残留第二管理员、所有 HTTP/运维写入口拒绝、普通账号改密仍正常、根环境隔离与同配置多副本、真实浏览器只读展示与授权边界。旧测试中“超级管理员可自助改密”和“可创建第二超级管理员”的前提需要替换，不能为保留这些历史行为放宽新规则。


## 本轮纠正与全局列表规范

本轮按用户截图与 Chrome 对 GitHub 当前设置页的只读调研直接修订，不新增产品字段或虚构编辑功能。头像 Settings 是设置入口，Profile 是资料子页；System 是管理入口，避免 Personal settings / Administration 在窄菜单中断行。只借鉴页面组织，不引入 Primer 组件替换现有 shadcn。

所有分页数据表默认每页 10 条，提供模板已有的每页 10/20/30/40/50 选择、页码、首末页及前后页。分页状态由 TanStack Table 的原生 PaginationState 管理；改变条数归第一页，查询缓存键和 API limit/offset 同步变化。成员、角色、组织、审计以及角色详情成员表必须一致；选择器的搜索候选与权限复选集合不机械分页截断。

设备管理的公开接口与专用模型/查询/文案删除；会话存储、登录验证、退出、密码变更撤销、跨标签和权限 SSE 等安全基础设施不属于删除范围。配置托管唯一超级管理员规则不变。

## 信息减负（用户再次纠正）

移除所有管理页标题下、Tab 下的功能复述、资料维护说明、登录页重复说明和默认表单填表提示，不以缩短文案替代删除。组织状态属于组织详情字段，不独立悬浮，也不重复组织名称。必要错误、危险确认、格式约束与凭据限制保留；配置密码说明通过相关控件的悬停/键盘焦点按需展示。专业本地化按场景与行业习惯表达，避免逐字硬译。
