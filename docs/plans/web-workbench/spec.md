# 安全智驾工作台与服务职责收敛

## 已批准范围

采用已讨论的 Console 职责建议，并按用户要求清理整包迁入但未使用的模板页面和菜单。仪表盘只保留 CRM V1，项目名称使用“安全智驾工作台”；后续功能按需求从固定模板版本选择性接入。真实 IAM 登录、账号安全、组织及管理功能保留。

## 服务边界

- IAM 拥有身份、会话、组织、角色与授权规则；Web 的 IAM 请求继续经同源入口送到 IAM，不增加 Console 包装接口。
- Console 是安全运营业务后端，未来承载案件、运营查询、工作台及必要的跨域查询汇总；不作为全平台强制转发层，不复制其他模块 CRUD。
- 模块拥有业务状态、事务与审计；Console 不访问其他模块私表，不重复实现 Agent 执行、处理管线或 SOAR 长流程和审批状态机。
- 当前 Console 的组织上下文与授权检查事件流保留，不描述为已实现业务工作台或业务事件流。

## Web 行为

- `/dashboard` 使用原 CRM V1 卡片、图表和表格，保持其组件、样式与示例数据；页面明确展示为模板示例，尚未接入安全运营数据。
- 继续位于真实 IAM 认证边界内。Dashboards 分组仅有一个工作台入口，英文为 Dashboard、中文为“安全智驾工作台”，按[国际化方案](../web-internationalization/spec.md)切换；组织、平台管理和账号入口按原服务端能力投影保留。
- 删除其他模板页面、演示身份、导航与搜索入口，旧演示 URL 返回 404；`/dashboard` 是唯一工作台主路由，根入口和登录后的返回位置统一使用它；不保留 `/home` 别名。
- 主题入口、浅深色快捷切换、既有共享 UI、字体、主题和真实身份菜单保留；主题控件移至项目共享组件，不依赖已删除的演示路由。
- 删除被移除功能专用的组件、数据、资源与依赖；不修改保留功能的依赖版本，不动生成契约和用户并行修改的 IAM 实现。

## 模板接入标准

模板仓库作为只读参考，按功能复制页面和必要的依赖闭包。复用项目现有 UI、样式、字体和锁文件；不复制模板身份体系、根配置或已删除页面，不覆盖项目改动。接入业务 API 时遵循模块归属与服务端授权，不把示例数据称为真实统计。保留许可和根 README 鸣谢，不在仓库记录个人工作区绝对路径。

## 验收

仅本地类型、构建、单元及必要浏览器检查；不创建测试容器，不执行部署、CI 或 Git 写入。确认旧演示 URL 不可访问、CRM V1 主体与基准一致、IAM 路由和权限入口仍在；未运行的真实认证 E2E 明确记录。
