验收日期：2026-10-29。状态：架构迁移及独立审查修复均完成本地分层验收，修复后 Preview E2E 7/7 通过，未执行 Git 交付、应用容器构建、部署或远程 CI。以 [Spec](spec.md)、[Plan](plan.md) 为准；早期方案、失败与阶段性结果见 [历史记录](history.md)。

## 实现与职责

| 内容 | 当前结果 |
| --- | --- |
| 原生 HTTP | IAM/Console 的公开、内部、健康与 SSE 入口由 Gin 注册；binding/validator、错误链、Recovery 和流式保持实际语义 |
| 模型归属 | IAM HTTP 模型归 internal/model，权限目录归 authorization，内部共用类型归 iamclient，结果与错误码归 result |
| 删除范围 | 集中 contracts、OpenAPI、Swag 注释、Hey API/Redocly 配置和依赖、生成 SDK/Query/core/responses 均已删除 |
| Web | Axios 1.21.0 负责传输，Zod 拥有消费模型并推导 TS；Query/RHF 使用原生能力，密码不进入 MutationCache |
| 最小自动化 | 仅保留实际跨语言共用的权限键和结果码四份常量导出，生成与只读检查通过 |
| 配置 | YAML 唯一默认源；根环境、模块覆盖与派生端点明确；直接 Next 入口，无 Caddy/5174 或重复 Web 端口键 |
| 导航 | 普通侧栏仅工作台；头像单一管理入口，管理 URL 恢复上下文侧栏并提供返回；390px 导航后关闭抽屉 |
| 业务不变量 | 组织隔离、委派/最后管理员、版本、事务/审计、会话提交/撤销和故障关闭保留 |
