## 原生 Gin 与无 OpenAPI 收敛（当前修订）

用户确认不保留 OpenAPI 与集中 contracts；本节取代前文中的现行工具链结论，前文绿色结果仅为历史。

- 原生 IAM/Console 路由、Binding/validator、严格输入边界、PATCH 可选值和共享响应已落地；`src/contracts` 已删除。IAM 模型归模块，权限业务目录归 authorization，共用内部类型归 iamclient，结果码归 result。
- 删除所有 Swag 注释、OpenAPI 文档、Hey API/Redocly 配置及依赖、生成 SDK/Query/core/responses；根生成命令仅保留业务目录四份常量导出。Web 使用 Axios 1.21.0 与消费 Zod，TS 从模型推导，原生 Query/RHF；密码不进入 MutationCache。
- 业务侧栏仅 Dashboard；头像单一管理中心入口，URL 决定管理上下文侧栏，返回工作台；390px 点击导航关闭抽屉。二次认证错误由现有表单错误区可见显示。
- 配置为三应用直接 Next 入口，无 Caddy/5174；根环境保留公开 URL 和不同含义的绑定 host，旧重复 Web 端口键已清理。Go YAML 是默认值唯一源；私有连接及凭证未改。
- 根脚本 24 项、Web 14 文件/32 用例、Go 全包单元、共享 HTTP/内部客户端 race、类型检查与 golangci-lint 通过。Biome 无错误，保留现有 data 表格嵌套条件警告和两项提示。
- 新增真实 HTTP 异步 Zod 解析交错测试：移除身份范围断言时实际失败，恢复后通过；无效确认、迟到 401、错误密码、缓存移除及错误正文不泄漏断言随消费者迁移保留。
