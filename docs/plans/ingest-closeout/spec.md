# Ingest 首版收尾

状态：功能已实施并通过联调，持续容量验收待达标。

## 目标

完成数据源原型中尚未交付的管理流程，使操作员能通过 Web 建立、检查和维护三种协议的接入点。用独立测试资源验证 Web、IAM、Ingest 与 Console 的现有契约，并为接入链路留下可重复的验收证据。

## 管理流程

- 数据接入页延用管理页的标题、工具条、表格和详情抽屉。新建按「选映射 → 样本试算 → 选协议 → 填连接信息 → 检查并启动」组织，保留明确的通用接入路径。HTTP 显示一次性令牌；Syslog 校验端口；Kafka 校验 broker 列表和 topic。可从详情复制设备配置，敏感字段按需显示。
- 接入点可改名、启停和换映射。HTTP 令牌轮换前说明旧令牌会失效，轮换成功后只展示一次新令牌。物理删除前显示接入点名称与停止收包的后果。权限沿用 IAM 目录。
- 解析映射以样本驱动的字段表单编辑，按格式显示相关配置，既有高级规则保留完整编辑能力。只有当前映射和样本试算成功才可按向导的正式映射路径继续。结果展示逐样本 OCSF 输出、未映射字段、严重度与用于选分区的实体，标出关键字段填充和失败原因；试算不写入业务事件。
- 诊断依据真实接收及发布数据，显示接入点最近收包时间、启停状态、接收和解析失败统计。当前样本或时间窗口无数据时明确显示空态，不推导出健康结论。删除仍被引用的映射时说明阻止原因及引用方。
- 内置首个 FortiGate CEF 流量映射，可选用及复制为自定义映射。内置规则只读，以厂商公开字段契约编写原创建议配置，回归样本使用虚构标识与文档保留地址，覆盖常见通过、拒绝、端口、严重度、时间及字段缺失。真实设备回放须使用允许发布或仅限本地测试的样本。 [FortiOS CEF 流量日志字段定义](https://docs.fortinet.com/document/fortigate/7.0.8/fortios-log-message-reference/949981/traffic-log-support-for-cef)

## 审计与运行验收

- 管理操作的鉴权继续由 IAM 判断。Ingest 成功写操作对应的审计事实与业务变更一同持久化，独立投递到 IAM。首次投递和重试均使用入队时间作为 `occurred_at`，同一事实只入账一次。IAM 审计暂不可用时，已经成功的管理操作仍返回原有业务状态，待投递记录可观测。保持现有服务审计的 `system` 主体与决策关联，投递记录不保存 Cookie、CSRF 或设备令牌。授权拒绝维持既有处理；设备推送不写管理审计。
- CI 集成入口实际运行 Kafka 最早位移和失败重投用例。补一项真实 broker 的同实体分区与顺序验证，以及定时运行的有限时长解析 fuzz。按层复用现有测试，浏览器只验核心流程和权限边界。容量验收记录输入形态、环境、吞吐、P99、GC 与队列积压，按实际结果报告是否达到持续 5 万 EPS。
- 模块 README 和架构资料说明当前服务名、路由、两个输出 topic 及其保留策略。文档区分基线迁移、实际验收和后续平台能力。

## 界面约束

复用现有 shadcn 组件与 SecPlexus 的管理页模式。参考模板的用户表、表单字段、抽屉和危险操作弹窗。中英文消息成对维护；权限、删除后果、失败恢复出现在操作发生的位置。桌面和窄屏均验证键盘操作、焦点、主题和长字段。
