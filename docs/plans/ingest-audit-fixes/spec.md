# 接入与解析规则走查修复

- 分隔符解析每次接收一条记录，保留引号内的换行。一个样本、Syslog 报文或 Kafka 消息含有额外记录时，返回原因码 `multiple_records`，样本标出需拆分的位置，实际接入按解析失败发布基础事件。HTTP 纯文本仍在接入层按行拆批。
- 规则保存和修订恢复后，列表和详情立即读取最新修订。编辑中的草稿由表单持有。
- Web 按 API 契约读取无条件分支，省略 `match` 或传入空条件时保留实际解析类型、事件类型和映射。仅改名称和描述沿用已验证定义与摘要。
- 规则详情展示最近一次验证的通过数和时间。编辑期间继续显示样本计数，服务端保存验证摘要。
- Syslog 详情区分服务内监听与设备访问地址，提示容器部署时发布 TCP 或 UDP 端口。部署指南提供覆盖文件示例。
- Ingest 文档使用实际解析规则 API 路径，并给出源码直连和 Compose 同源的设备推送地址。
