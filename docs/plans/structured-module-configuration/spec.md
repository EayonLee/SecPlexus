# 模块配置与日志收敛

> Web 基准更新：本文的 Arco/Vite/Redux 前端实现记录已由 [Web 整体替换计划](../replace-web-template/plan.md) 承接。现采用 Next.js/shadcn 基准并重建 IAM 页面；服务端业务与授权契约继续有效。


2026-10-28，按本次用户指示实施。

Go模块直接维护`config.yaml`，按app、db、redis、业务策略、logging分组；host和port分开，端口为整数。文件内`${ENV:default}`声明环境变量与默认值。移除instance_id、连接文件、通用Secret文件和.local目录。Console只配置自己实际使用的能力。

数据库、Redis和认证敏感信息直接通过环境变量/私有.env注入。TLS证书仍为文件。根.env.example按中文注释分组，实际.env不提交；Web保留Vite原生.env.example和.env，不增加YAML加载器。

本地/二进制默认记录结构化日志到根logs目录，两个模块独立文件；支持级别、大小、保留份数/天数和压缩。容器默认stdout并由日志驱动轮转；显式挂载可以启用文件日志。不能多个副本写同一文件。

保持既有认证、权限、迁移、CSRF、内部TLS和应用权限约束；配置错误不输出敏感信息。普通启动不部署依赖。模块独立运行与根一键启动读取同一配置。缺.env仍首次生成提示检查、不覆盖已有值。


## 统一连接修订（2026-10-28）

本次按用户明确要求调整：默认一个PostgreSQL实例、一个数据库、一组账号密码，运行、迁移、维护全部使用同一连接。模块的db字段默认引用全局SPX_POSTGRES_*，需要独立连接时修改该模块config.yaml字面值或占位声明；不增加平行的IAM_DB、迁移/维护账号配置和建账号脚本。账号需要本项目建表及迁移权限，取消旧的运行账号禁止DDL检查，保留schema版本检查、应用鉴权与审计事务。

根.env按Web、IAM、Console、PostgreSQL、Redis分区；只保留常用配置。根启动读取模块实际监听配置生成本地代理与内部调用URL，显式远程URL作为可选覆盖。Redis固定使用 spx 前缀，通过类型化模板构建 spx:模块:业务:标识的 key。注释写明实际用途，不使用泛称“敏感信息”等含糊描述。
