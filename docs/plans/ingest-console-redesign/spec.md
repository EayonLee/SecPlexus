# 控制台数据接入重构

状态：已实施并完成联调与浏览器验收。

## 目标

数据接入是控制台的业务功能。操作员从工作台旁的「数据接入」进入，可以配置日志接入、确认收到第一条数据、定位接收或解析问题。日常维护从接入点列表出发，解析规则作为可复用配置独立管理。

现有 Web 把接入点和解析规则放在设置侧栏，与[原先批准的主导航原则](../ingest-and-normalization/spec.md#七导航与模板基线第四轮用户指出)不一致。新建抽屉把映射与样本放在通道之前，随后还要经过独立的通道、连接和确认页。详情把收包证据、连接参数和立即生效的修改放在同一个窄面板；从书签也无法打开某个接入点。

### 共享布局与数据呈现

Web 的控制台外壳为所有路由提供内容框架，顶栏与页面使用同一宽度和边距。全宽模式使用侧栏之外的全部空间。桌面居中模式取可用空间的 92%，最大 80rem；窄屏优先保证正文宽度。业务页面只编排内容，创建表单、连接预览和映射试算根据可用宽度换列。实现与回归覆盖见 [Web 布局](../../../src/apps/web/README.md#console-layout)。

借鉴 [Elastic EUI 的页面模板](https://github.com/elastic/eui/blob/main/packages/eui/src/components/page_template/page_template.tsx)在外层统一约束宽度，以及 [Grafana 的 Page](https://github.com/grafana/grafana/blob/main/public/app/core/components/Page/Page.tsx)组合标题、导航和正文的方式。通道筛选器显示实际接入点计数，操作与接入点关联。空状态提供三个协议的创建入口；新建页实时呈现所选协议的连接方向和参数。桌面映射编辑与结果并排，移动列表优先名称、收包时间和操作。

## 导航与页面

| 地址 | 页面 | 权限 |
| --- | --- | --- |
| `/ingest` | 数据接入首页。根据权限打开接入点或解析规则。 | 接入点、映射至少一类可读 |
| `/ingest/inputs` | 接入点，默认页 | 接入点读 |
| `/ingest/inputs/new` | 新建接入点 | 接入点读、写 |
| `/ingest/inputs/[id]` | 接入点诊断与连接配置 | 接入点读；写操作另需写权限 |
| `/ingest/mappings` | 解析规则 | 映射读 |
| `/ingest/mappings/new` | 新建解析规则 | 映射读、写 |
| `/ingest/mappings/[id]` | 查看或编辑解析规则 | 映射读；自定义映射编辑另需写权限 |

控制台主侧栏有独立的「数据接入」组，组内的「数据接入」与「解析规则」分别由各自的读取权限控制。进入创建、编辑或详情时，所属菜单保持选中。旧地址 `/settings/ingest` 和 `/settings/mappings` 跳转到对应新地址。登录回跳、前进后退和直接访问深链都经过现有身份与权限校验；导航隐藏时直接访问也要拒绝。设置侧栏移除两项入口。

### 接入点列表

数据接入列表提供名称、协议、解析规则、启用状态、当前进程接收量、解析失败量、最近接收时间和行操作。点击非零引用数打开已按这条规则筛选的接入点；只有具备接入点读取权限时才展示引用列。两列表均支持分页、过滤无结果后恢复、保留筛选返回，并在新查询或切换每页条数时回到第一页。

- 名称进详情，行末菜单放次要操作。列表支持按名称、通道、启用状态查找，返回时保留筛选。默认以列表开工，主按钮位于页首，表格上方保留筛选。
- 「启用状态」反映保存的开关。「最近接收」显示实际统计；没有当前进程统计时显示「暂无记录」。停用的接入点仍可查看已有时间。映射已绑定但无映射读取权限时显示「已绑定」，未绑定时显示「通用解析」。
- 管理员可勾选当前页的接入点，确认后批量启用或停用。只更新需变更的记录，部分失败时保留失败项供重试。
- 初次为空时，可写用户从空态创建；筛选无结果可清除筛选；读取失败可重试；只读会话没有编辑入口。

### 新建接入点

| 阶段 | 操作 | 完成条件 |
| --- | --- | --- |
| 选择接入方式 | 选择已有解析规则或使用通用接入，并确认通道。按实际传输链路选择 Syslog、HTTP 或 Kafka。 | 用户确认通道；有映射读、写权限时可选择并试算映射。 |
| 配置连接 | 一屏填写名称和所选通道必填项。HTTP 生成端点及凭证；Syslog 填 UDP/TCP 共用端口；Kafka 填 broker 与 topic。绑定映射时在「解析验证」粘贴实际样本并查看试算。 | 表单通过，绑定的映射与当前样本全部通过试算；创建失败时填写内容保留。可切换通用解析完成创建。 |
| 确认接收 | 创建成功直接进入详情，查看发送参数、首包状态和诊断入口。 | 可区分「接入点已创建」和「已收到数据」；无需等设备侧就绪即可离开。 |

模板在 Web 使用现有内置映射标识，校验映射实际可用再推荐。已有自定义映射也可选择。无映射验证权限的接入点管理员仍可按通用解析接入；已有绑定继续使用，具备对应权限的人员可试算并显式保存新绑定。样本、映射或映射版本变化后重新试算。试算失败提示具体样本与原因，支持修改、重试或切换通用解析。试算结果仅证明样本解析，连接由创建后的实际接收验证。

### 接入点详情

打开名称进入独立详情页。依次显示基本信息、所选协议的连接配置、绑定的解析规则和接收诊断。详情沿用模板个人资料页的标签和值布局。编辑操作打开同一路由的表单，返回列表后恢复查询条件。

- 诊断显示最近接收时间、处理事件数和解析失败数，数字口径为当前 Ingest 进程处理记录。缺少统计时提供对应通道的首包检查项；有解析失败时引导核对映射和试算。定期刷新仅在诊断可见时运行。页面保留最近成功读取的证据，刷新失败单独反馈并允许手动重试。
- Syslog 显示端口和 UDP/TCP，并提示使用设备可访问的接收主机。Kafka 显示 broker 与 topic，引导检查生产端发送位置。HTTP 展示设备端 URL 路径和带占位符的请求示例，部署地址来自实际设备可访问入口。创建或轮换返回的明文令牌只在响应后的当次交互展示，可复制，刷新后不可取回。
- 编辑名称和更换映射须显式保存；更换只影响后续日志。启停、删除、轮换集中在操作入口。停用、删除和轮换有具体后果提示。协议、Syslog 端口和 Kafka 订阅参数按现行契约在创建时确定。

### 解析规则

- 按名称、描述、厂商与产品检索，可组合规则来源和解析类型。当前契约见[接入来源与规则清单](../ingest-source-identity/spec.md)。
- 表格显示规则名称和描述、厂商与产品、解析类型、来源、引用数、版本和更新时间，按表格自身可用宽度保留优先列。规则和接入点分别使用独立菜单和地址。
- 规则详情可逐步查看配置和已保存的样本预览。内置规则可以复制，自定义规则可编辑或复制，解除数据接入绑定后可删除。
- 编辑器左侧填写基本信息、格式参数和样本，右侧核对源字段、OCSF 路径和逐字段输出。未映射字段可直接添加到映射，再用同一样本验证。完整预览保留分区键、归一化事件和逐条失败原因。配置、字段或样本改变后，上一次的结果失效。单次最多验证 50 条样本。
- 规则引用数和接收统计以现行数据契约为准。当前服务未提供规则依赖树、威胁分类、工作节点、24 小时告警数或解析耗时。

## 验收

- 从主导航进入数据接入，刷新与分享有权访问的详情链接、旧书签跳转与直接访问拒绝均符合权限。设置侧栏、折叠图标导航和移动侧栏指向同一套路由。
- 在隔离栈验证 HTTP 推送、Syslog 收包和 Kafka 订阅，能区分创建、接收、解析失败与权限拒绝。通过实际样本验证 FortiGate 映射及自定义映射，覆盖失败修复、通用解析回退、配置修改及凭证轮换。
- 在真实浏览器检查常用桌面和窄窗口、中英文和明暗两种主题。确认列表密度、连接参数换行、映射编辑器、键盘焦点、空态和错误状态。计数、状态、时间和示例均与实际证据或部署条件相符。
