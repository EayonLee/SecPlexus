# 按事件类型配置解析规则与字段映射

状态：向导与规则校验已实施 · 2026-11-27

## 统一标准

SecPlexus Event 以 **OCSF 1.10.0** 为唯一领域标准，锁定版由 Ingest 的 [`event-contract.json`](../../../src/apps/ingest/schema/events/event-contract.json) 管理。事件类别、类、活动、字段路径、类型、单位、基数、枚举和标准约束均取自同一版本。平台契约 `v1` 发布该版本中已支持的子集，统一供映射页、试算、接入、归档、查询和模型使用。 [锁定版本的 OCSF Schema](https://github.com/ocsf/ocsf-schema/tree/2d209039d9c476ab76e83fb58b6f99374d40a994)

厂商日志的原始字段和编码在接入模板转换为 OCSF。中文展示名和搜索别名由 Ingest 目录维护，例如「登录事件」可找到「认证活动」中的登录动作。平台扩展按归属单独标注，例如 `metadata.spx` 记录解析状态和接入追溯信息。常用类按有实际样本、能满足 OCSF 字段要求和可验收的顺序纳入。上游升级统一评审契约、模板及下游兼容性。

## 基础配置决定输出范围

新建规则在「基础配置」选择一个具体的事件类型。事件类型和解析类型同排展示。规则名称、数据源厂商、数据源产品、规则描述及至少一条日志样本必填。已有多类型自定义规则可继续按已配置的条件分流。当前安装从空规则列表开始。公共基础字段来自 OCSF Base Event 的继承定义。未分类和失败日志由数据面生成诊断记录。

| 概念 | 解决的问题 | 界面位置 |
|---|---|---|
| 事件类型 | 这条日志记录了什么，决定输出字段、条件、枚举和验证规则。界面使用 OCSF Event Class，存储和查询以 `class_uid` 表达。 | 基础配置，映射页只读显示 |
| 数据源模板、厂商、产品 | 日志从哪里来，可以复用什么解析和分流配置。一台防火墙可以产生网络、认证等多种日志。 | 基础配置的可选模板或来源信息 |
| 解析类型和接入协议 | JSON、CEF、键值对等决定提取方法。HTTP、Syslog、Kafka 决定如何接收。 | 解析类型在规则基础配置，接入协议在接入点 |
| 事件时间来源 | 从哪个源字段读取及转换时间。源时间的单位、格式和时区取决于数据源。 | 套用模板时预填，手动配置在映射页的「事件时间」行 |

类型目录展示标准类别及其事件类型。全量字段目录以事件类型为一级入口，共有且语义一致的字段可从「公共基础字段」查看。第三步已经确定事件类型，当前类的字段选择器仅列出适用于该类型的字段，类内可按账号、端点、活动等对象分组。事件类型和 OCSF 序号都由目录提供，保留与活动类型 `activity_id`、复合类型编号 `type_uid` 的区别。

登录、登出等操作名称可用于搜索并在预览显示。安全设备的入侵检测、普通流量及上游检测结果按各自的标准类和 Profile 表达。候选事件类型、可用来源模板和验收覆盖见[命名与覆盖计划](plan.md#事件类型命名与覆盖范围)。

## 规则详情与管理列表

新建、编辑和查看详情共用同一套四步布局、字段控件和日志样本。规则名称与「查看详情」进入只读页。自定义规则可通过「编辑」进入修改，内置规则可通过「复制规则」生成草稿。只读模式可自由切换步骤和样本，显示已保存的提取结果、映射与事件预览。临时输入样本保留在编辑会话内。没有保存样本的规则仍可逐步查看配置。操作菜单提供查看详情、编辑、复制和删除等授权操作。

解析规则列表按规则名称、描述、数据源厂商和产品搜索，可按事件类型、解析类型和来源筛选。既有多类型规则在任何已配置的事件类型下均可查到。「数据接入」数量链接到按该规则过滤的数据接入列表。数据接入列表按名称、数据源厂商和产品搜索，并可按解析规则、协议及状态筛选。解析规则列表省略版本列。两张列表默认每页 20 条，筛选和页码随 URL 保留。

共用模板 Invoice 的表单与预览布局和 Tasks 的可换行工具栏。事件类型和解析规则筛选与其他列表筛选共用紧凑高度、字段名和选中值布局。展开时用空输入开始搜索，收起时显示已选项，默认选项统一为「全部」。弹层跟随完整筛选控件定位，宽度适应选项并受视口限制。选项单行展示，超长省略；解析规则筛选只列名称。数据接入的规则筛选复用绑定规则的远程搜索。共享关键词搜索框在有效宽度不足时省略长文本，保留完整可访问名称。[模板采用说明](../ingest-operator-workflows/spec.md#从-dashboard-模板采用哪些页面设计)

## 四步操作

| 步骤 | 工作区 | 进入下一步 |
|---|---|---|
| 基础配置 | 规则信息、事件类型、解析类型和可编辑日志样本。 | 校验规则信息、类型范围、解析器设置和每条样本。失败提示关联到字段或样本。 |
| 提取字段 | 左侧的工具栏包含搜索和「添加字段」。列表显示源字段、样本值、类型和「裁剪」「解码」。右侧是三行只读样本，已有多类型模板在这一步查看或维护「日志分流」。 | 至少一条样本完成提取。处理配置和分流条件有错时定位到对应条目。 |
| 字段映射 | 先显示可配置的公共基础字段及本类必配条件对应的字段，再显示可移除的常用字段。标准字段和源字段都显示类型。标准字段标签保留整数、IP、时间戳和数组元素类型等信息。添加映射在表格末尾聚焦标准字段。右侧保留只读样本。 | 核心行常驻。未满足必配条件或同一作用域的源字段冲突时留在当前步骤，聚焦对应行，保留已有选择。样本值的类型和枚举由试算验证。 |
| 预览保存 | 事件类型与解析状态显示在结果上方。结果用「字段结果」和「OCSF JSON」切换，日志样本与结果相邻。默认值标在使用它的行内，字段错误从对应行返回修改。 | 按当前草稿的试算结果保存。列出分流样本覆盖情况，未覆盖的分流单独提示并确认。已引用规则继续使用预期修订和影响确认。 |

## 哪些字段是核心

核心分三种。**输出必需项**由事件规范决定，平台能生成的字段显示来源，看得到且无需手选源字段。**必配映射**由本类必须满足的字段或字段组决定，可配置源字段或符合契约的默认值。**推荐映射**用于提升查询、告警和研判质量，可以跳过。若某字段在具体场景才必需，例如有 HTTP 响应时需要状态码，只有配置或样本触发条件后才要求补齐。

核心行允许清空当前来源以便改配，行仍保留。备选字段按同一个条件组校验，例如认证服务和目的端点至少配置一侧。平台已能提供的接收时间、未知严重度和未知活动沿用规则输出。常用选配行可以从当前草稿移除，并通过「添加字段映射」找回。

| 范围 | 预置到第三步 | 可以手动添加的示例 |
|---|---|---|
| 公共基础字段 | 事件时间显示来源，允许映射日志时间或明确使用接收时间。严重度可配置来源映射，保留「未知」。事件 ID（`metadata.uid`）由接入运行时自动生成并贯穿试算、发布和归档。正式事件 ID 使用接入点及接收序号等上下文生成，表单不提供输入。活动类型行共用布局，取值按当前类提供。事件摘要可推荐。 | 本类允许的活动名称、状态相关字段、产品版本。编码为「其他」且契约要求伴随说明时，展开必填项。 |
| 网络活动 `4001` | 「源端点／目的端点至少配置一侧」是一组要求。可填写 IP、主机名、设备标识等已支持的端点身份字段。源 IP、目的 IP、端口和协议可按使用价值推荐。 | 本类支持的连接方向、端口、协议、流量等字段。 |
| 认证活动 `3002` | 提供认证用户，例如账号名称或账号 ID。认证服务和目的端点至少选择一项可满足的映射。登录／登出等活动和操作结果优先推荐。 | 本类支持的源 IP、认证机制、认证会话或结果详情。 |

用户选择源字段时可以搜索各条实际样本提取的字段、派生字段和手动补充的路径，也可录入未在样本中出现的源路径。源字段缺失的样本显示「本样本未出现」，与类型错误分开。添加映射只能选本类支持、可写、尚未配置且没有路径冲突的标准字段。切换事件类型时预览仍适用、需要重新选择枚举、将被移出的映射，确认后应用。复制规则、查看内置规则和返回修改均按同一规则呈现。

例如选择「认证活动」后，第三步预列「账号名称」`user.name` 和「账号 ID」`user.uid`，根据发布契约显示可满足认证用户要求的路径。用户可把日志中的 `account` 选给「账号名称」，把 `server` 选给「目的主机名」`dst_endpoint.hostname`。目的主机名满足目的端点要求时，认证服务可以留空。有结果字段时可把来源值 `failed` 映射为「失败」`status_id=2`。已有同一条样本的源字段和值显示在右侧供核对。

## 补充源字段

- 「添加字段」使用平台窄抽屉，可逐行追加、删除并一次应用。每行填写源字段路径和可选样本值。路径使用解析器实际提取的命名，如 JSON 的 `user.name`、分隔符格式的 `field_2`。输入路径时检查空白、长度、重复、已提取字段及保留字段。每个草稿上限 32 项，错误显示在对应行。
- 类型默认自动判断。原生 JSON 解析识别数字、布尔、数组、对象和 `null`；普通文本保持字符串。下拉可指定字符串等类型，例 `00123` 资产编号保持原样。空白样本值表示暂无示例。对象与数组作为预览值，点路径的子字段仍需明确选择。
- 补充项让操作者完成映射配置，即使当前样本未出现该路径。样本值仅在当前编辑会话展示，标记「手动补充」。真实报文优先；正式试算和运行时按报文提取字段。输出预览缺少该字段时提示更换或补充实际日志样本。规则保存源字段路径及映射，补充样本值不进入规则修订、审计、日志或 Event。

## 字段处理

- 源字段行有「裁剪」和「解码」两个入口，各打开同一规格的窄抽屉。数值、布尔、空值和结构化值展示禁用态。抽屉显示脱敏、限长的原值。表单仅展示所选操作所需参数。「预览结果」用当前日志样本执行同一提取流程，处理结果与原值均为可滚动的三行展示。预览阶段不改动规则，错误在抽屉内显示。
- 去除首尾空白沿用现有操作。文本裁剪支持去除明确前缀或后缀，并定义前后缀不匹配时的试算提示。解码优先 Base64、URI 和十六进制。嵌入 JSON 继续按路径提取。独立 Unicode 转义解码在有设备样本验证后纳入，JSON 自带转义由 JSON 解析处理。
- 输出写入独立字段，保留原始值供排障。应用前校验目标冲突、不合适的值类型、缺失参数、过长值和非法编码。处理顺序可串联，使用现有处理项上限与大小边界。失败仅影响该项，其他字段可以继续提取。派生结果继承脱敏限制。

## 默认值、校验与真实日志

- 默认值属于映射行的标准输出。字段路径不存在时使用默认值；真实字段已出现但值非法、显式为空或转换失败时保留原诊断。数字 0、布尔 false 均是实际值。清空默认值恢复原行为。平台生成时间、严重度等已有回退，按其专用配置说明。
- 控件读取标准字段逻辑类型和基数。枚举控件及结果表显示名称，编码保留在规则和 JSON 中。HTTP 方法默认列出常用方法，完整 OCSF 枚举可搜索。HTTP 状态码下拉提供常用登记值，同时接受 100–599 的整数输入。事件时间的默认值用下拉显示「接收时间」，未设置的控件留空。共享映射的枚举值须满足对应输出类别的值域。历史常量在界面显示为默认值。
- 配置检查回答「规则是否提供了满足契约的映射」。对同一作用域的缺项、目标冲突、非法值和非法分流返回可定位的问题。样本与运行时检查回答「这条日志是否真的有合规结果」。已有合规映射遇到单条数据缺失或格式错误时，继续按当前行为记录解析状态、原因和候选类，必要时输出基础事件。映射行没有用户自定义的必填开关。
- 「操作结果」描述事件发生了什么，例如登录失败。「解析状态」描述平台是否正确提取、归一化。同一条登录失败日志可以解析成功。字段详情提供当前契约的适用类型、数据类型、字段路径、枚举代码、中文释义和可定位的来源链接。

## 验收

- 多行补充可以一次应用，类型自动判定和人工指定都准确。重名、无效路径及与真实源字段冲突能回到具体行。
- 处理前后值可核对。条件、失败原因、派生字段及敏感值策略在提取试算、完整试算和实际入流中一致。
- 同一映射作用域有重复目标时阻止试算，定位冲突的各行。不同且互斥的分类可配置各自目标；共享映射与分类映射合并后仍须通过冲突检查。
- 可分别新建认证活动和网络活动规则，也可继续使用带分流的 FortiGate 模板。运行时按诊断策略生成基础事件。第三步只检查各自的目标和必配项。网络活动只有一侧有效端点、认证活动用服务或目的端点均可通过。缺少条件组时错误落在对应组。
- 告警、查询和后续模型使用同一套标准路径、枚举、单位及类别语义。规则层不能改变已发布字段的编码、类型和值域。
- 各步骤可用键盘完成，宽屏、窄屏和明暗主题下验证样本宽度、焦点归位、字段选项层级和错误恢复。
