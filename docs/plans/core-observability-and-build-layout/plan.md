## 实际结果与验证

- 2026-10-28：共享 logging 补请求字段、安全错误分类和代码位置；HTTP 记录规范路由、请求标识/状态/字节/耗时，提前拒绝同样可定位；panic 不输出原始值。IAM 管理事务记录动作、资源、阶段和提交结果，认证成功等到 SCS 保存之后；会话加载/保存/补偿、撤销、改密、PG/Redis 故障与慢操作、内部调用和 SSE 均补关键记录。覆盖点与字段见 [运行诊断](../../observability.md)。
