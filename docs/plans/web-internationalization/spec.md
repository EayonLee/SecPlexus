# Web 中英文国际化

## 已批准需求

工作台英文名称固定为 Dashboard，中文名称固定为安全智驾工作台。全平台提供英文与简体中文切换，使用专门的国际化库与独立消息词典，不在页面中按语言编写条件分支。现有英文内容采用准确的中文业务表达，不机械逐字翻译。

## 方案与边界

- 模板没有全站国际化实现；使用 next-intl 接入 Next.js App Router。词典、语言配置和切换入口归 Web 模块，不引入另一套 UI 框架。
- 支持 en、zh-CN，默认英文；语言选择存 Cookie，服务端渲染、客户端、文档语言及页面元信息一致。URL 和 API 契约保持现有路径，不新增语言前缀或修改 IAM 认证。
- 登录、导航、工作台、主题偏好、个人账号、IAM 管理表单/表格/对话框、通知、错误及无障碍文本纳入词典。后台错误按稳定 code 映射本地文案，不显示内部错误正文。
- 日期、数字、金额与复数通过国际化格式工具处理；切换语言不改变金额币种、业务状态或权限。姓名、组织名、账号、邮箱、资源ID等业务数据不翻译。
- CRM 示例仍按销售业务含义翻译，不把营收、线索等伪装成真实安全统计；明确保留示例说明。
- 保留现有组件、样式、主题和字体基准。只修改实现本地化必要的文本接口，不改后端接口、数据库、部署或服务职责。

## 验收

- 两份词典键一致，消息变量/复数与格式可用，消息键具备 TypeScript 类型约束，新增语言有明确入口。
- 英中文页面命名准确，切换及刷新后语言保留，html lang 与元信息一致，登录页也可切换。
- 类型、构建、相关单元检查及必要浏览器检查通过；不构建容器、不部署、不执行远程 CI 或 Git 写入。真实登录验收受现有凭据限制时明确记录。
