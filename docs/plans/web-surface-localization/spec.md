# Web 表面层级与国际化入口

本规范覆盖工作台、数据接入、解析规则、系统设置，以及这些路由打开的菜单、弹框和抽屉。所有页面从根主题和共享壳层取得外观，按现有导航目录进入。账号、权限、路由、查询和数据写入契约沿用现有实现。

| 区域 | 浅色 | 深色 |
| --- | --- | --- |
| 画布、页间留白 | `#ffffff` | `#0a0a0a` |
| 侧栏、卡片、列表、资料区、编辑器、浮层 | `#fafafa` | `#171717` |
| 明确的分组或内嵌次级区域 | `--muted` | `--muted` |

主操作、焦点和选中状态沿用 `DESIGN.md` 的品牌蓝。列表表头、数据行及分页继承列表表面。弹框、抽屉、浮层菜单使用 `--popover`，通过描边、阴影或背景遮罩表达层级。全宽与居中使用同一壳层，新增路由继承当前偏好，包括从浮层 Portal 渲染的组件。

服务端按请求解析语言、时区和消息目录，并传给客户端根入口。缺失或格式错误的翻译使用可读回退并保留诊断。筛选器优先保留已有的字段名与选项名。中英词典须对齐，稳定的 IAM 权限说明按权限键翻译。已存储的角色名称、描述和其他业务数据以 API 返回为准。

验收核对已登录页面、创建向导、编辑器和典型浮层的明暗层级、窄屏及键盘操作。切换中英文后经菜单导航、打开筛选与弹框、刷新，并检查翻译错误和暴露的内部键。
