# 本机访问来源兼容

修复配置公开入口为 127.0.0.1 时，localhost 页面登录被来源校验拒绝的问题。仅当公开入口本身是 localhost、127.0.0.1 或 ::1 时，接受相同协议和端口下的这三个明确回环主机；不接受其他主机、不同端口或协议，不信任转发头扩展来源。非回环公开入口仍只接受其精确配置来源。

Origin 校验通过后，CSRF 库按本次允许的来源主机验证，保留 Cookie、签名令牌、SameSite、TLS 和服务间授权约束；不能通过替换 Origin、关闭 CSRF 或允许任意来源来绕过问题。不改 API、数据库或远程依赖，不新增环境模式开关。

验收：localhost 与 127.0.0.1 都能真实浏览器登录、访问管理/账号安全并退出；单元覆盖精确来源、回环别名、错误端口/协议、外站及缺少令牌的拒绝；生产域名不获得回环别名。测试会话独立，不改用户已有标签或配置。
