本轮在开发环境中逐个点击了 16 个菜单入口，并检查登录页、各页面的主要控件和共享设置。菜单的实际目标地址保存在同名 JSON 中。重复列表按操作类型检查，没有把每条随机 Mock 记录当作不同功能重复验证。

## 本轮修复

- 统一图表坐标文字和网格的主题颜色优先级，避免深色模式被页面写死的浅色覆盖。
- 给工作台环图的外侧标签留出明确宽度，浏览器已确认 `16% / 36% / 48%` 都完整显示。
- 分开设置折线默认颜色与悬停白色填充，浏览器已确认提示框圆点为蓝色。
- 空头像显示图标，不再生成无地址的图片；头像选择仅在本地预览，并释放旧的临时 URL。
- 修正个人信息保存提示直接显示翻译键的问题。
- 处理登录和分组表单校验失败的 Promise 拒绝。
- 头像菜单中的用户设置、工作台、卡片列表接入已有路由；隐藏导航后的浮动设置按钮补上名称。
- 修正编号筛选提前返回、忽略其他条件的问题；已验证编号加不匹配名称得到空结果。
- 删除卡片页无作用的数字表达式。
- 用当前 Arco 的自定义触发器替换主题色控件外层的旧弹层，消除必须再点一次小色块才能取色的问题；禁用不适用于品牌色的透明度。

## 尚需注意

保留了官方页面内容，没有把占位按钮补成虚假的业务成功。上表中的占位功能不能作为真实业务验收通过。

Arco 在 React 19 下仍产生 `element.ref` 兼容提示，部分模板组件还产生列表 key 提示。本轮没有修改依赖源码或屏蔽日志。生产构建不包含开发 Mock，IAM 和 Console 后端尚未接入。
